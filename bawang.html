中药世家的特证防脱老牌

表活 / 去屑剂 / 防脱植萃 / 硅油（专业词）

⚠ 冲突标注：营销"氨基酸表活 / 无硅油 / 无硫酸盐" vs 备案（SLES + 硅油）

电商与品牌传播中常见"氨基酸无硅油无硫酸盐"话术，但备案成分显示表活为月桂醇聚醚硫酸酯钠（SLES）+ 月桂醇硫酸酯铵（硫酸盐系，非氨基酸），且含聚二甲基硅氧烷（硅油）。两者直接矛盾，本报告以备案为准；此外基础款 20258240 完整成分表未检索到（成分来自同线变体），淘宝"上市 1928"为误标（实为 1989），均标注待核。

产品启示

如果做新锐国货防脱品牌，怎么打？

不打霸王的"中药世家 + 特证老牌"正面战场，而是用"同特证合规 + 空白透明 / 温和 / 无硅油 / 年轻化"切入。五条可执行策略：

  1. 特证合规是壁垒。承接"国妆特字育发类"合规防脱心智，以持特证建立宣称合法性，正面切霸王的专业带而非绕开。
  2. 成分透明化。补霸王"基础款完整成分未公开"短板，把全成分与浓度明示，借"备案为准"建立可信沟通。
  3. 温和表活 + 无硅油选项。补"含 SLES + MIT / 含硅油"短板，做氨基酸 / APG 温和表活与无硅油变体，切敏感头皮与无硅油需求。
  4. 年轻化沟通。补"老化营销 / Duang 梗陈旧"短板，用社媒与科学传播做年轻化，承接新锐用户。
  5. 切信任洼地。直击霸王"营销氨基酸无硅油无硫酸盐 vs 备案 SLES + 硅油"矛盾，用"说备案、做备案"建立信任差。
