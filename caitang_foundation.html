产品启示

如果做新锐国货粉底，怎么打？

不打彩棠的"唐毅专业 + 分肤三版"正面战场，而是用"同分肤度 + 空白价格 / 防腐透明 / 包材"切入。五条可执行策略：

  1. 分肤精准。承接"专为中国面孔分肤定制"心智，用干/混油/油三版 + 三调五色，切 DW/毛戈平之下的专业需求。
  2. 磁吸替换。补"正装占地、无泵"短板，把旋转按压泵 + 磁吸替换遮瑕芯做成复购差异点。
  3. 养肤透明。把油橄榄叶 / 蜂胶 / 泛醇等养肤添加浓度明示，借彩棠已验证的"养肤底妆"趋势做透明沟通。
  4. 价格带卡位。用 ¥150-250 价格带，切在国际持妆标杆（DW/兰蔻 ¥200-490）与高端国货（毛戈平 ¥380）之间的空白。
  5. 新手友好。针对分肤选版门槛，做选色指引 + 分肤教程 + 肤质自测，降低上手难度。
