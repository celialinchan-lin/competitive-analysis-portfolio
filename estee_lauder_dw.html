产品启示

如果做新锐持妆粉底，怎么打？

不打 DW 的"国际持妆标杆 + 全球长青"正面战场，而是用"同持妆力 + 空白包材 / 肤感 / 价格"切入。五条可执行策略：

  1. 硅系成膜持妆打底。承接 DW 已验证的"硅系成膜 24h 级持妆"心智，用同等成膜技术建立"长青持妆"信任，正面比拼持妆力。
  2. 泵头改良。补 DW"无内置泵、难取量"短板，标配按压泵头，降低用量浪费与上手门槛，做成体验差异点。
  3. 干皮友好版。针对 DW"干皮易卡粉"痛点，做保湿基底 / 干皮友好版，承接被 DW 劝退的干皮与混干用户。
  4. 养肤升级。补经典版"偏纯粹持妆"，加入烟酰胺 / 透明质酸 / 虎杖发酵等养肤成分，借 DW 新版趋势做透明沟通。
  5. ¥150-250 价格带。卡在 DW 跨境价与官方价之间的空白，用"同持妆 + 更友好包材肤感"切其之下的升级需求。
