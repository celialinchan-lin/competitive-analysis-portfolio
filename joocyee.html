产品启示

如果做新锐修容品牌，怎么打？

不打酵色的"设计师质感 + 液体多用"正面战场，而是用"同液体 + 空白肤质 / 声量 / 聚焦"切入。五条可执行策略：

  1. 油皮适配液体。承接"液体修容"心智，用控油成膜基底补酵色油皮移位短板，切油皮 / 混油人群。
  2. 声量放大。补"品牌声量小"短板，用小红书 / KOL 内容投放 + 修容教程建立认知。
  3. 修容线聚焦。补"霜 / 盘 / 笔 / 棒分散"短板，主推 1-2 个核心形态，降低用户认知成本。
  4. 好评率补齐。补"数据缺失"短板，统一京东 / 天猫口碑口径，提升可信度。
  5. 成分透明。把养肤添加浓度明示，借酵色已验证的"养肤液体修容"趋势做透明沟通。
