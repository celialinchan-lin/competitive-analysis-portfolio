EP.29 · 旁氏 Pond's 米粹

旁氏 米粹 控油净透
平价氨基酸洁面的"竹炭吸附"标杆

联合利华旗下亚洲护肤（1886 美国创立），针对学生党/年轻油皮的平价控油洁面线。核心用氨基酸表活（椰油酰甘氨酸钠）+ 竹炭物理吸附 + 烟酰胺，把"温和清洁 + 吸油 + 调皮脂"做进一支二十元级洁面，是开架平价控油的心智第一梯队。

一句话结论：米粹控油净透用"氨基酸温和 + 竹炭物理吸附 + 烟酰胺调皮脂"的平价组合，把旁氏的学生党基本盘做成"控油洁面入门款"；亮点在极致性价比 + 大容量 + 氨基酸温和 + 联合利华渠道，短板在功效基础非强效、防腐体系传统(DMDM)、缺临床背书。C·电商快照

核心成分 / 机理

米粹控油净透的核心机理：氨基酸温和清洁 + 竹炭物理吸附多余油脂 + 烟酰胺（辅助调皮脂/提亮），是"清洁 + 吸油"的入门组合。A/C

烟酰胺调皮脂/提亮辅助调控皮脂、亮肤低浓度

温和度

形态

以洁面为主，洗去式，非驻留控油；控油靠吸附而非调皮脂。C

产品启示

如果做新锐控油品牌，怎么打？

不打旁氏的"低价 + 渠道"正面战场，而是用"同价格带 + 空白安全/背书/分肤"切入。五条可执行策略：

  1. 同价格带、无传统防腐。承接"平价氨基酸控油"心智，做无DMDM等温和防腐版，正面回应旁氏防腐顾虑的学生敏感肌痛点。
  2. 平价 + 临床背书。用独立临床数据补旁氏"缺临床"短板，把安全信任做成平价带差异点。
  3. 学生敏感肌分线。在平价带内做"油皮/痘敏"分线，抢"通用平价"之外的细分。
  4. 驻留控油形态。补旁氏"洗去式"缺口，做平价控油凝乳/水，延长控油时长。
  5. 机理组合创新。在竹炭吸附之上加锌/烟酰胺调皮脂，从"吸附"升级为"吸附+调皮脂"双效。
说明：以上为基于旁氏公开竞争态势的"我方（假设为新锐控油品牌）"策略推断，非任何品牌官方信息。我方定位/价格/渠道需结合实际业务定义。
