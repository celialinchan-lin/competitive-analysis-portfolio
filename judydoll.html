产品启示

如果做新锐修容品牌，怎么打？

不打橘朵的"极致低价 + 多形态"正面战场，而是用"同价格带 + 空白工艺 / 包材 / 肤质"切入。五条可执行策略：

  1. 粉盘防结块工艺。承接"平价精准修容"心智，用湿用友好压粉密度 + 硅处理，正面回应橘朵粉盘偏干结块。
  2. 高光持久升级。补"高光不持久"短板，用成膜聚合物提升扒肤，切重妆 / 高频补妆人群。
  3. 磁吸防开包材。补"外壳无卡榫"短板，把卡榫 / 磁吸防开 + 轻量化做成差异点。
  4. 油皮适配版。补"油皮 T 区卡粉"短板，用控油成膜基底做油皮专属修容。
  5. 入门→进阶梯度。在单色 / 液体之外做进阶综合盘，承接想升级的用户，不限于纯入门。
