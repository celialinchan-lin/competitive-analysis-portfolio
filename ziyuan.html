配方拆解

表活体系 / 硅油替代 / 植萃（专业词）

滋源无患子控油清爽洗头水的"配方"= 表活体系 + 无硅油证据 + 硅油替代柔润 + 植萃添加 + 去屑 / 舒缓 + 防腐。以 SLES + CAPB + APG + 椰油酰胺甲基 MEA 为主清洁体系，此款无氨基酸表活；全成分未含聚二甲基硅氧烷，无硅油属实。A

无硅油确证

产品启示

如果做新锐无硅油洗发水，怎么打？

不打滋源的"无硅油开创者 + 百万评论"正面战场，而是用"同无硅油 + 空白表活 / 温和 / 透明"切入。五条可执行策略：

  1. 真·无硫酸盐氨基酸。补滋源"含 SLES、控油款非氨基酸"短板，用氨基酸 + 真无硫酸盐表活建立"无硅油又温和"的配方信任。
  2. 敏感头皮友好。补"含 SLES + 香精刺激"短板，以无香精 / 低刺激 + 舒缓（如甘草酸二钾）覆盖敏感头皮人群。
  3. 成分透明化。把表活体系、无硅油证据、去屑 / 舒缓剂浓度明示，借滋源"营销无硫酸盐但备案含 SLES"的信任洼地做透明沟通。
  4. 北方干冷版加滋润。针对控油清爽偏干涩，做干冷版加滋润调理（替代柔润剂升级），降低对护发素的依赖。
  5. 年轻化沟通。以成分党语言 + 透明标注 + 蓬松香氛，切滋源偏传统的沟通与"国妆特字"错标待核的信任缺口。
