产品启示

如果做新锐国风底妆，怎么打？

不打花西子的"国风声量 + 百万评论"正面战场，而是用"同养肤 + 空白价格 / 干皮友好 / 包材"切入。五条可执行策略：

  1. 超细粉体柔焦。承接气流粉碎超细粉体心智，做柔焦隐形毛孔的定妆散粉，与粉底液形成互补而非替代。
  2. 养肤植萃透明化。补花西子"养肤量未公开"短板，把珍珠 / 蚕丝 / 赤芝 / 桃花等养肤成分浓度明示，建立敏感肌信任。
  3. 国风包材轻量化。补"香粉盒略重"短板，做雕花 + 内置镜 + 绒粉扑的轻量磁吸升级，兼顾颜值与便携。
  4. 干皮友好版。针对干皮拔干痛点，出保湿 / 珠光版，覆盖北方干冷与干皮人群。
  5. ¥100-150 价格带。占国风散粉定妆心智，与粉底液（¥200+）互补，避开粉底液正面价格战。
