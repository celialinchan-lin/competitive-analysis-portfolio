产品启示

如果做新锐蓬松洗发水，怎么打？

不打 Spes 的"干发喷雾破圈 + 香氛 + 融资"正面战场，而是用"同蓬松 + 空白信任"切入。五条可执行策略：

  1. 无硅油氨基酸 + 亚美尼斯强韧。承接"蓬松丰盈"心智，用无硅油氨基酸表活 + 亚美尼斯分子（二氨基嘧啶氧化物）强韧发根，切油头 / 细软塌 / 扁塌人群。
  2. 香氛差异化。借 Spes 已验证的"小苍兰沙龙香"趋势，做定制调香 + 调香师 / 奖项背书，建立香氛记忆点。
  3. 销量实证透明。补 Spes"绿胖子单品销量未公开 / 3 天不油缺实证"短板，用第三方长期盲测 + 公开销量建立信任。
  4. 地域适配扩展。补"北方干冷偏干涩"短板，做干冷滋润版 + 配套护发素，覆盖全地域。
  5. 信任洼地切入。整体切"蓬松宣称缺实证"的信任洼地——同蓬松 + 换实证 / 换透明，是后来者最清晰的切口。
