产品启示

如果做新锐修容品牌，怎么打？

不打彩棠的"唐毅背书 + 亚洲肤色适配 + 渠道"正面战场，而是用"同价格带 + 空白持妆 / 包材 / 色号"切入。五条可执行策略：

  1. 珠光持久升级版。承接"亚洲肤色修容"心智，用成膜聚合物提升珠光扒肤与持妆，正面回应浮光掠影珠光需补的顾虑。
  2. 防指纹 / 便携包材。补彩棠"外壳易沾指纹"短板，把哑光防污材质 + 更轻量 mini 做成差异点。
  3. 色号向深扩展。在灰粽阴影之外做深肤色专属阴影，抢极深肤色（彩棠适配边界）之外的信任。
  4. 膏粉双拼 / 液体修容。换质地（彩棠已出双拼高光粉膏），用膏体遮瑕 + 粉体定妆的一盘多用切新手。
  5. 修容教育 + 底妆协同。从单盘修容扩展到"修容 + 底妆 + 遮瑕"全脸轮廓方案，借彩棠已向底妆扩张的趋势做协同。
说明：以上为基于彩棠浮光掠影公开竞争态势的"我方（假设为新锐修容品牌）"策略推断，非任何品牌官方信息。我方定位 / 价格 / 渠道需结合实际业务定义。

一句话总结
