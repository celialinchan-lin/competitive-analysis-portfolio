产品启示

如果做新锐国货去屑洗发水，怎么打？

不打 KONO 净屑舒爽的"平价走量 + 明星背书"正面战场，而是用"真去屑剂实证 + 透明 + 温和 / 无硅油"切入。五条可执行策略：

  1. 真去屑剂是底线。去屑是高频刚需但监管严（ZPT 已限用），立项应真添加合规去屑剂（OCT / 吡罗克酮乙醇胺盐），而非用"净屑"话术规避；净屑舒爽"无去屑剂却宣称去屑"正是反面教材。
  2. 做实功效测试。去屑宣称须有人体功效试验支撑，把报告与数据公示，建立"说得出、证得了"的信任差，直击净屑舒爽证据缺口。
  3. 成分透明化。补"去屑成分与宣传冲突、待核"短板，全成分 + 去屑剂名称与含量明示，借"备案为准"建立可信沟通。
  4. 温和表活 + 无硅油选项。补"硫酸盐 + 硅油"短板，做氨基酸 / APG 温和表活与无硅油变体，切敏感头皮与无硅油需求。
  5. 切诚信洼地。直击净屑舒爽"去屑宣称 vs 成分无去屑剂"的诚信缺口，用"真添加、真测试、真公示"建立信任差，而非话术包装。
